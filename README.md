# 나의 학습나침반 - AI 기반 자기주도학습 시연 앱

전공자율선택제 대학생이 교과목 학습을 중심으로 목표 및 계획을 세우고 자료를 읽으며 스스로 수행, 점검, 성찰 및 조정할 수 있도록 지원하는 **학습자 주도형** 웹앱입니다.

## 사용 경로

- 앱: https://sdl-ai.streamlit.app/
- GitHub: `seulyi2332/sdl-ai-preview`
- Streamlit Cloud 배포 브랜치: `main`, 실행 파일: `ai_preview_app.py`
- 기존 시연 버전 보관 브랜치: `backup/before-compass-redesign-20261027`

## 화면

1. **오늘**: 학습 방향, 할 일 4개 상태(시작 전, 진행 중, 도움 필요, 완료), 최근 학습일지 브리핑 및 흥미 또는 어려움 표시, 필요하면 AI와 대화
2. **목표와 계획**: 장기 및 단기 목표 표현, 할 일 카드 상태 변경, 선택적 날짜, 숨기기 및 복원
3. **공부하기**: PDF 업로드 및 실제 원본 페이지 보기, 문단 선택 후 어려움/흥미/핵심/질문 표시, 교과목 맞춤 학습전략 2~3개, 학생 직접 비교표와 풀이 작성, AI와 자연스럽게 대화
4. **학습일지**: 학생의 자유로운 서술, 원문 근거가 있는 AI 범주화 및 브리핑, 학생의 확인과 수정 후 기록, 선택에 따른 목표 추가 및 자기평가
5. **내 기록**: 표시한 문단 모아 보기와 유형별 필터 및 숨기기, 직접 수행한 활동, 지난 일기

**PDF 표시 기능은 드래그 방식이 아닌 문단 선택 방식**입니다. 정확한 위치 하이라이트를 자동으로 삽입하거나 OCR로 이미지 문서를 읽는 기능은 지원하지 않습니다.

## 실제 API 연동

Streamlit Cloud의 앱 Settings → Secrets에서만 다음 설정을 입력하세요. 실제 키를 GitHub 또는 채팅에 게시하지 않습니다.

```toml
OPENAI_API_KEY = "본인의 실제 API 키"
OPENAI_MODEL = "gpt-4o-mini"
```

API 키가 없으면 학습전략은 카탈로그 기반 참고 방법을 제공하지만 실제 GPT가 생성했다고 표시하지 않으며, AI 학습일지 및 자유로운 대화에는 오류를 안내합니다.

## 공개 시연 및 자료 보호 경고

**이 앱은 실습 및 개발 시연용입니다.** 공개 URL 및 `DEMO01` 코드는 안전한 사용자 인증이 아니고 서버 로컬 SQLite 저장자료는 재시작이나 재배포 시 손실될 수 있습니다. 실제 연구 참여자 자료, 민감한 학습일지, 개인정보 또는 비공개 강의자료를 입력하거나 연구 평가용으로 곧바로 사용하지 마세요. 실제 연구에 사용하기 전에는 사용자 분리, 동의 절차, 접근제어와 영구 저장을 구축하고 검증해야 합니다.

기존 평가용 `sdl-prototype` 저장소와 DB는 별도로 운영하며 이번 공개 시연 앱으로 자동 이전하지 않습니다.
