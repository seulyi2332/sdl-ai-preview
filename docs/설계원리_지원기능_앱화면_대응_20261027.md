# 설계원리와 지원기능 및 앱 화면 대응 관리표 (2026-10-27)

## 용도와 검증 기준

본 문서는 박사학위논문의 **자기주도학습역량 촉진을 위한 AI 기반 앱 프로토타입** 개발근거를 추적하기 위한 작업표이다. 앱에서 버튼이나 화면이 보이는 것만으로 설계원리가 충족되었다고 보지 않는다. 문헌 및 전문가 검토를 거친 **개별 세부지침 원문과 F1~F19, C1~C3 번호의 일치** 여부는 별도의 현재 설계원리 원본표를 기준으로 대조해야 한다.

- `기초 구현`: 해당 기능을 수행하는 실제 코드와 사용자 조작 화면이 존재한다. 교육적 효과와 실제 API 성능이 검증되었다는 뜻이 아니다.
- `부분 구현`: 설계원리 일부만 기능으로 표현된다. 세부지침별 확인이 필요하다.
- `미구현`: 요구되는 핵심 기능의 실제 작동 경로가 현재 시연 앱에는 없다.
- `실사용 검증 필요`: 테스트 더블이나 로컬 UI 자동 테스트와 달리 실제 GPT, 실제 PDF, 사용자 흐름에서 추가 검증이 필요하다.

**중요:** 이 표는 공개 저장소 `sdl-ai-preview`의 `compass_main.py` 기반 신규 시연 앱 현황이다. 비공개 `sdl-prototype` 평가 앱에 존재하는 기능을 신규 시연 앱의 구현으로 간주하지 않는다. 사용자 평가 결과도 아직 반영하지 않았다.

## 시연 화면별 기능구조

| 앱 화면 | 학생의 주요 행동 | AI의 역할 | 확인할 데이터 및 증거 |
|---|---|---|---|
| 오늘 | 목표 및 할 일 확인, 시작 및 질문 선택 | 질문에 대한 설명과 근거 및 선택지 제공 | 메인화면 캡처, 선택 전에 AI가 상태를 확정하지 않는지 확인 |
| 목표와 계획 | 목표와 기간 작성, 할 일 상태 직접 이동, 숨김과 복원 | 현재 버전에서는 자동 목표 작성 없음 | 목표 및 할 일 조작 전후 화면과 SQLite 상태 |
| 공부하기 | PDF 문단을 직접 선택해 어려움 및 흥미 표시, 전략 선택, 비교표와 풀이 수행 | 과목 및 어려움 기반 전략의 이유와 예시, 선택한 문단의 설명 | 원본 PDF 화면, 유형별 표시, 전략 카드 및 학생 직접 수행 결과 |
| 학습일지 | 자유 서술, AI 브리핑 수정, 목표 후보 선택, 스스로 평가 | 일기 원문에 근거한 범주화 및 브리핑 초안, 선택적 목표 후보 | 일기 원문과 정확한 인용, AI 초안, 학생 수정과 저장 확인 |
| 내 기록 | 표시한 문단과 학습활동 다시 보기, 숨기기 및 복원 | 학생 요청 시 관련 내용 설명으로 연결 | 분류별 PDF 표시 카드, 숨기기 및 복원 시나리오 |

## 논문에 실을 핵심 기능 후보

1. **교과목 맞춤 학습전략 제안과 학생의 능동적 수행**: 학생의 어려움과 교과목을 입력하면 AI가 방법과 이유를 제시하고 학생은 전략과 활동을 직접 선택한다.
2. **PDF 학습 흔적의 선택적 수집 및 활용**: 학생이 중요하다고 생각한 문단을 어려움, 흥미, 핵심, 질문으로 기록하고 유형별로 모아 다시 학습할 수 있도록 한다.
3. **학생의 자유로운 학습일지와 근거 기반 AI 브리핑**: AI는 학생 원문의 근거가 확인된 경험을 요약하고 학생이 수정한 뒤 기록한다.
4. **성찰에서 목표 및 계획으로의 연결**: 학습일지에 근거한 목표 후보를 제시하되 학생이 선택한 항목만 실제 목표에 추가한다.
5. **목표와 계획의 학생 주도 관리**: 완료한 할 일은 시각화하되 이를 목표 달성 퍼센트나 자기주도학습역량 점수로 오해하지 않도록 구분한다.
6. **교과목 학습과 관심 전공의 연결**: 현재는 학생의 흥미 표시 및 성찰 기록에 부분 구현되어 있어, 논문 핵심 기능으로 주장하려면 추가 개발 및 시연 검증이 필요하다.

## 실증 자료 수집 절차

- 각 핵심 기능마다 화면 캡처 ① 최초 상태 ② 학생의 실제 입력과 선택 ③ AI의 근거 및 선택지 제공 ④ 학생의 수행 및 결정 ⑤ 저장 후 다시 보기 순서로 남긴다.
- 앱의 API가 실제 호출되었는지와 결과가 AI 생성인지 카탈로그 기본 예시인지 구분한다.
- 17개 설계원리의 **개별 세부지침 전체**를 줄 단위로 대조하고, 관련 지원기능 F1~F19의 번호는 기존 확정 기능구조표와 직접 비교하여 기록한다.
- 형성평가 의견과 반영사항 및 사용성 평가 결과는 독립 열로 관리한다.
- 새 시연 앱의 자동 검사 통과는 '코드 기능 검사'일 뿐 자기주도학습역량의 향상 효과를 증명하지 않는다.

## 평가 전 반드시 유의할 점

현재 공개 시연 앱은 서버 로컬 SQLite에 데이터를 저장하고, DEMO 코드 자체는 인증수단이 아니다. 실제 학생의 개인정보, 학습일지 또는 비공개 PDF를 저장하는 연구용 시스템으로 간주해서는 안 된다. 연구용 평가 앱의 별도 참여자 관리, 데이터 보존, 고지와 동의, 백업 조치가 필요하다.
